# Safwan Vk — Portfolio

Creeto-inspired personal portfolio built with [Astro](https://astro.build), deployed to [GitHub Pages](https://safwanvk.github.io).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` run [.github/workflows/deploy.yml](.github/workflows/deploy.yml). In the repository **Settings → Pages**, set **Build and deployment** source to **GitHub Actions**.

Place `Safwan Resume.pdf` in `public/` if you host the resume on this site (linked at `/Safwan Resume.pdf`).
